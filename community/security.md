# Security

Security updates are provided for the latest stable release of `php-n8n/client`.

## Supported Versions

| Version | Supported |
| --- | --- |
| v1.0.2 | Yes |
| v1.0.1 | No |
| v1.0.0 | No |

## Reporting A Vulnerability

Please report security vulnerabilities privately and do not disclose them publicly until they have been reviewed.

Send reports to:

```text
contact@php-n8n.com
```

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or versions.
- Any proof-of-concept code or screenshots, if applicable.

You should receive an acknowledgement within 7 days. Valid security issues will be investigated and addressed as soon as possible.
